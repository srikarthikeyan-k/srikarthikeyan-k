## 🚀 Featured Projects

### 01. Vision Based Smart White Cane for Visually Impaired Individuals

**March 2026 – April 2026**

An AI-powered smart assistance system designed to help visually impaired individuals navigate their surroundings.

**Key Features:**
- Real-time object detection using YOLOv8.
- Obstacle detection using ultrasonic sensing.
- Voice guidance for navigation assistance.
- Vibration feedback for obstacle alerts.
- SOS emergency alerts through Twilio WhatsApp API.
- Raspberry Pi 5-based embedded AI implementation.

**Technologies:**

`Python` `YOLOv8` `OpenCV` `Raspberry Pi 5` `Flask` `NumPy` `Twilio API`

---

### 02. Crop Disease Detection Using Convolutional Neural Networks

**May 2026**

A deep learning-based application designed to classify crop leaf images as healthy or diseased.

**Key Features:**
- Crop leaf image classification using CNN.
- Image preprocessing and dataset preparation.
- Model training using TensorFlow and Keras.
- Interactive web application using Streamlit.
- Real-time disease prediction from uploaded leaf images.

**Technologies:**

`Python` `TensorFlow` `Keras` `OpenCV` `NumPy` `Streamlit`

---

### 03. OP-Amp Based Water Level Detection

**January 2025 – May 2025**

An electronic water level monitoring system designed using operational amplifiers.

**Key Features:**
- Water level detection using sensing probes.
- Operational amplifier-based voltage comparison.
- LED indicators for different water levels.
- Detection of water presence at multiple levels.

**Technologies:**

`Operational Amplifier` `Analog Electronics` `EasyEDA`

---

### 04. Smart Gas Safety Valve and Cylinder Monitoring System

**July 2025 – November 2025**

An IoT-based gas safety and cylinder monitoring solution designed to improve safety through automated monitoring.

**Key Features:**
- Gas leakage detection using MQ-6 sensor.
- Automatic valve shut-off mechanism.
- Remote gas leakage alerts.
- Gas level monitoring using load cell and HX711.
- ESP32-based real-time processing.
- Cloud connectivity for remote monitoring.

**Technologies:**

`ESP32` `Arduino IDE` `MQ-6 Sensor` `HX711` `IoT`
